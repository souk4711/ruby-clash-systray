# ClashSystray

A simple system tray for Clash on Linux.

## Requirements

- [Ruby](https://www.ruby-lang.org/)
- [Qt](https://www.qt.io/)

## Installation

```console
$ gem install ruby-clash-systray
```

## Usage

To launch the GUI:

```console
$ clash-systray
```
